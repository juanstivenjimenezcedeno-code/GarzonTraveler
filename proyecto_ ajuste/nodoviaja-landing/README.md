# NodoViaja — landing page

Landing page responsive para descubrir destinos turísticos del Huila. Está construida en un único `index.html` con Tailwind CSS Play CDN y JavaScript nativo.

## Ejecutar

1. Descomprime el archivo.
2. Abre `index.html` en un navegador moderno. Para una experiencia más estable, puedes usar la extensión Live Server de VS Code.
3. Se requiere conexión a internet para cargar Tailwind desde CDN y las fotografías externas.

## Secciones

- **Principal:** hero visual, llamadas a la acción y navegación.
- **Beneficios:** cuatro propuestas de valor.
- **Nosotros:** propósito e identidad regional.
- **Métricas:** cifras de maqueta claramente marcadas como ilustrativas cuando aplica.
- **Recomendados:** tarjetas de negocios de demostración con precios y calificaciones de ejemplo.
- **Sitios:** carrusel horizontal con controles, indicadores, scroll táctil y navegación por flechas.
- **Footer:** enlaces y formulario de novedades.

-Inicio de sesión y registro conectados, los botones que llevan a los sitios por ahora no llevan a ningún lao
